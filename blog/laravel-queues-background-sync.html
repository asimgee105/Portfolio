Architecting Background Sync Queues in Laravel

Written by Asim Ali

When syncing database lists from third-party feeds (like property listings portals containing 20,000+ XML entries), running a single parser thread synchronously inside a web request is bound to trigger execution timeouts or exhaust PHP's memory limit. The solution is to decouple the file parser using Laravel Queues and Redis.

1. Streaming Parser with PHP XMLReader

Unlike SimpleXML or DOMDocument, which read the entire XML file structure into server memory at once, PHP's native XMLReader behaves as a pull parser. It reads the file node by node, consuming minimal memory regardless of whether the file size is 1MB or 1GB.

$xml = new XMLReader();
$xml->open($filepath);
while ($xml->read()) {
    if ($xml->nodeType == XMLReader::ELEMENT && $xml->name == 'property') {
        $node = simplexml_load_string($xml->readOuterXml());
        $chunk[] = json_decode(json_encode($node), true);
    }
}
