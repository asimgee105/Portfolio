## System Design Lab

Interactive architecture notes based on my Laravel projects:

- System Design Lab: https://asimgee105.github.io/Portfolio/system-design/
- Scalable Order API: https://asimgee105.github.io/Portfolio/system-design/order-api.html
- Laravel URL Shortener: https://asimgee105.github.io/Portfolio/system-design/url-shortener.html

- POS & Inventory System: https://asimgee105.github.io/Portfolio/system-design/pos-system.html

Each architecture page explains the project in three stages: a simple deployment, an approximately 1K-user architecture, and a larger approximately 100K-user architecture. The pages use animated request flows and explain why load balancing, Redis caching, queues/workers, read replicas, WebSocket scaling, event-driven processing, transaction consistency, and reporting isolation are introduced.
