How to read these pages

One system, three stages

Stage 1 — SimpleOne application instance and one database. Fastest to build and easiest to debug.
Stage 2 — ~1K usersAdd cache, queues and a second application instance only where bottlenecks justify them.
Stage 3 — ~100K usersSeparate high-load responsibilities, distribute traffic and protect databases from unnecessary work.
Decision firstEvery component is explained by the problem it solves, not because “big systems use it.”
